### Week 3 – Loops

Practice with `for` and `while` loops, comparing determinate and
indeterminate repetition.

- **Ounces to grams**: conversion table for 0–16 oz, written with both `for` and `while`
- **Ten Green Bottles**: song lyrics with a countdown loop and a helper function for plurals
- **Litres to pints**: conversions for 1, 2, 4, and 8 litres, generated by doubling
- **Shapes**: squares, rectangles, and triangles drawn with `#`, using single and nested loops
- **Repeating shapes**: keeps drawing until the user stops entering `Y`, with and without selection (`break`)
